# Dashboard Chart Presentation

呈现规则来自 `docs/designs` 的四块参考板。需要对齐观感时打开原图，不要另加装饰。

| 过程监控 | `docs/designs/2026-11-18_10h22_40.png` | 实线 / 目标虚线 / 事件点、异常区间与时间角标、空间小倍数 |
| 分析工作台 | `docs/designs/2026-11-19_09h01_36.png` | 主数字、构成条、反色强调卡、柱线组合、双线趋势、紧凑表 |
| 轻量事务板 | `docs/designs/2026-11-19_09h03_25.png` | 单强调色便当格、火花线、点阵日历、同心分层、卡片内动作 |

信息架构和业务问题交给 `enterprise-ui-ux-designer`。本技能只规定一块看板长什么样、一张图怎么编码。不取数、不清洗、不搭应用脚手架。

## 1. 先定一种看板

一块页面只属于一种。四种的密度、主题和允许的组件不同，混在同一屏会失去层次。

| 类型 | 适合的问题 | 主题 | 密度 | 表 | 主视觉 |
|---|---|---|---|---|---|
| 运行大屏 | 现在是否正常、谁最高、资源还剩多少 | 深色 | 低，数字大 | 不用 | 允许一块结构图 |
| 过程监控 | 相对目标偏了多少、偏在何时何地 | 深色 | 低，一问两图 | 不用 | 不用 |
| 分析工作台 | 总额从哪来、和上期比如何、谁贡献了 | 浅色 | 高，可下钻 | 可以 | 不用 |
| 轻量事务板 | 今天要处理什么、一两个数是否在变好 | 浅色 | 中，留白大 | 短列表即可 | 不用 |

页面标题说明对象（运营、厚度、收入、财务）。时间范围放在页头或卡片右上，不写进每张图的标题。

## 2. 卡片

每张卡片都是同一套零件，缺口径的数字不单独出现。

1. **标题**：指标名，短。
2. **口径**：一行。写清统计谁、总和还是实时、时间粒度。例：`所有应用的访客量总和 · 本日累计值`。
3. **主数字**：一块卡片只有一个主数字。单位贴在数字上：`1000 位`、`512 MB/s`、`99.93%`、`$528,976.82`。
4. **一个对照**：环比、目标、或绝对拆分。三选一。对照写明基准：`环比 7 天前 15.05%`、`vs prev. $501,641.73`、`Target (120.0 nm)`。没有目标就不画目标线，也不编红绿状态。
5. **图**：可选，放在口径和主数字下面，回答同一个问题。

工作台上需要同时扫多个结果时，大部分指标用描边小卡（名称、数字、一个增量）。只有一个结果用反色填满（黑或强调色），作为眼睛的落点。例：Best deal 用黑卡，Value 用强调色卡，其余保持白底。

金额在主数字上用精确值，在小卡上可以缩写（`$528k`）。同一指标两种写法要能对上。

## 3. 版式

### 运行大屏

左约六成是指标，右约四成是一块结构主视觉。阅读顺序：状态 → 趋势 → 排名 → 资源。

```
[ 标题                          时间范围 ]
[ 主指标 ] [ 主指标 ] [ 状态条 ] [          ]
[ 趋势              ] [ 趋势    ] [ 结构主视觉 ]
[ 排名              ] [ 排名    ] [          ]
[ 环  环  环                     ] [          ]
```

趋势卡紧挨在它解释的主指标下面。排名成对出现时共用同一种条形，不要一边条形、一边饼图。

### 过程监控

上图是时间，下图是空间。两张图用同一个度量。

```
[ 标题 + 图例 + 异常角标 ]
[ 实线序列 · 目标虚线 · 事件点 · 异常色带 ]
[ 空间小倍数一排 + 一条共享图例 ]
```

### 分析工作台

页壳可以有侧栏、搜索、协作者、时间范围、导出。内容区自上而下：主数字 → 构成 → 分解与表 → 趋势。

```
[ 主数字  增量  上期 ] [ 普通小卡 ] [ 反色小卡 ]
[ 构成条：各段 = 金额 + 占比，各段之和 = 主数字 ]
[ 分类卡 / 小环 ] [ 人员或类别表 ]
[ 柱 + 线，当期用强调色，旁注当期 ] [ 至多两条线 ]
```

### 轻量事务板

便当格，一种强调色。问候、日期和主按钮在第一行。账户、收支、占比、日历、火花线分格。任务、开关、评分可以占格，不必改成图。

## 4. 图表怎么编码

先选编码，再谈样式。一种比较关系只用一种通道。

### 主指标

大号数字 + 单位 + 一个对照。方向用箭头或正负号，颜色只是辅助：变好用绿（深色板）或强调色（浅色板），变差用红。色弱可读靠符号和文字。

一个指标的两侧（下行 / 上行、收入 / 已付）写成同一卡里的两行，或并排的两张同构卡，并共用周期切换。不要拆成两张互不影响的图。

### 状态条

问题是「这段时间是否正常」时用分段条，不用折线。绿段正常，黄段警告，红段异常。两端标注窗口（`90 天前` / `今天`）。主数字仍是当前值（`99.93%`）。

### 趋势线

问题是「今天怎么走」时用一条实线，可带浅色面积。横轴是粒度：`06:00`、`周五`、`Nov 01`。不画网格墙，不标每个点的值。同一块看板里的趋势线用同一个序列色。

过程监控里三条编码必须分得开：

- 实测：实线
- 目标：虚线，图例写目标值
- 事件：圆点，图例单独命名（如 AI Anomalies）

线的颜色不随异常改变。异常是额外一层。

### 异常

三件一起出现：圆点落在发生处，色带盖住区间，角标写结论和时间（`Anomaly Detected` / `Nov 05, 02:45 PM`）。只有色带或只有变红的线，不算标注完成。

### 排名条

类别比较用横向条，从高到低，默认前 5。名称在左，条长表示值，数值在条尾。条用同一个颜色。标题写排名依据：`按应用的独立访客量排名 · 累计数据`。

### 用量环

资源占用用环：环内是百分比，环侧是绝对量（`85 核`、`92 GB`、`820 GB`）。同一行多个环时，色相用来区分指标，弧长用来表示用量。超过约定阈值时才把弧改成状态色。一行最多三个环。

单一占比（增长率、完成率）用一个环，百分比在环心，环下写含义（`Growth rate`）。两个数的对比不用环，用一对数字。

### 构成条

主数字需要解释来源时，在其下方放一条分段条。每段标金额和占比。各段相加等于主数字。分类很多时改排名条，不用构成条。

分类只有少数几项时，可以用小环配列表（名称、金额、占比）。列表是主体，环只重复同一组成。

### 柱线组合

两个度量共享时间轴时：柱表示量，线表示另一个度量。图例写清哪个是哪个。当前周期的柱用强调色，其余用中性灰。被强调的那一期在图旁用三行摘要复述（如 Revenue / Leads / W/L），摘要数字与柱、线一致。

### 双线

同一轴上最多两条线。用线型和颜色区分，图例给出序列名。横轴上只在有名字的事件或对象处放标记。范围用一排短选项（`1W` `1M` `3M` `1Y`），选中项填强调色。

### 火花线

格内已经有主数字时，用无坐标轴的短线表示走势。线的两端标出比较对象（`2022` / `2023`）或只保留终点。单位放在旁边的数字上，不放在线上。

### 点阵日历

问题是「哪些天有活动」时用点阵，不用把每天画成折线点。有活动的点用强调色，空日用浅灰。旁边用一句话给总数（`13 Days`）。

### 同心分层

数值是同一度量的嵌套层级（如利润带）时用同心圆，金额标在每一环上。这不是构成图，各环不必相加。层级多过四层时改回排名条。

### 空间小倍数

同一对象沿时间或批次重复（晶圆、区域、班次）时横排小图，共用一条图例和同一色标。标题写在整行上：`Wafer Map (Thickness Deviation)`。偏离类用发散色：低值冷色，高值暖色，图例两端写 `Low` / `High`。不要每张小图各做一条图例。

### 结构主视觉

拓扑、分布、地图可以占大屏右侧。它必须表达关系，并且带一句计数口径：`60 个应用（129 个容器）分布在 50 个节点上`。柱、趋势、排名不要做成三维。

### 不是图的格

清单、主按钮、评分、账户操作留在卡片里。评分用一排表情或档位，选中项用强调色。不要为了填满网格把动作改成无意义的图。

## 5. 颜色

一块看板一种强调色。强调色只标记：当前周期、选中对象、主按钮、唯一的反色小卡。

状态色单独使用，不拿来当品牌色：绿是正常或变好，黄是警告，红是异常或变差。深色运行大屏的序列线用绿。浅色工作台的序列线用强调色，对照序列用中性灰或蓝。

环和图用色相区分指标时，不再用色相表示好坏。状态要另加文字或图标。

背景：运行大屏和过程监控用近黑底、略抬起的深色卡片；工作台和事务板用浅灰底、白卡片、大圆角、轻阴影。同一页不混用两套底。

## 6. 坐标、图例与空状态

- 图例放在卡片内标题行，序列名带单位：`Mean Thickness (nm)`。
- 轴标题在单位已经出现在图例或主数字里时可以省略，刻度保留。
- 时间窗口写在页头或角标上，轴上只留刻度。
- 零和缺失分开：缺失断开或留白，不用 0 填。
- 没有数据的卡保留标题和口径，主数字位置写 `—`，不画空坐标轴。
- 小数位跟随精度：比率靠近 100% 时可以到两位；计数不用小数。全板同一类指标位数一致。

## 7. 出图时写清的规格

每张图用下面几行交代，没有的项写「无」，不要留空让实现自己猜。

```
看板类型：运行大屏 | 过程监控 | 分析工作台 | 轻量事务板
卡片：标题 / 口径 / 主数字 / 单位 / 对照
编码：线 | 状态条 | 排名条 | 环 | 构成条 | 柱线 | 双线 | 火花线 | 点阵 | 同心圆 | 小倍数 | 结构主视觉
轴：横轴维度与粒度；纵轴度量；是否从零开始
标注：目标线 | 事件点 | 异常色带 | 角标 | 无
强调：哪一个点、柱、人或卡使用强调色
图例：序列名
和谁对齐：哪一个主数字必须与本图合计一致
```

## 8. 呈现自检

- 这页只属于一种看板。
- 每张卡能在三秒内读完：是什么、多少、相对什么。
- 主数字、构成条、组合图旁注、表内金额能互相核对。
- 对照要么是环比，要么是目标，要么是绝对拆分。
- 异常同时有点、色带和带时间的角标。
- 小倍数共用色标；排名条同色并按值排序。
- 强调色只出现在一个角色上。
- 三维只用于结构主视觉。
- 页面时间范围只出现在页头或卡片控制上。
